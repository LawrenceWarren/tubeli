# TLI (tube-line-interface)

This project aims to create a CLI for fetching tube times. By default, there will be a user interface for you to fetch information about a given station's or line's status. Alternatively, using CLI flags, you'll be able to immediately fetch the same information, rather than having to navigate an interface.

_[Jonathon's guide](https://departureboard.jonathanfoot.com) for creating a raspberry pi tube-time board, the inspiration for this project_
